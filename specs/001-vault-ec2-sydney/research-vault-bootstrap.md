# Research: Vault Bootstrap Pattern

## Question

What module composition pattern can deliver a Vault server plus Windows and RHEL instances that install Vault Agent and authenticate to Vault over TLS using a self-signed CA issued by the Vault server?

## Findings

- The likely composition pattern is:
  - one networking module for the VPC and subnets
  - one security-group module for operator and Vault traffic controls
  - one Vault-capable compute module for the server
  - one generic compute module instantiated for RHEL and Windows clients
- The client instances need bootstrap support to:
  - install Vault Agent
  - trust a CA generated by the Vault server
  - render an agent configuration file
  - configure auto-auth to Vault
- The Windows requirement is explicit: use an AMI lookup equivalent to:

```hcl
data "aws_ami" "hc_base_windows_server_2025" {
  filter {
    name   = "name"
    values = ["hc-base-windows-server-2025-x64-*"]
  }
  filter {
    name   = "state"
    values = ["available"]
  }
  most_recent = true
  owners      = ["888995627335"]
}
```

- Minimum port exposure implied by the request:
  - `22/tcp` from operator IP to Linux hosts
  - `3389/tcp` from operator IP to the Windows host
  - `8200/tcp` from operator IP and client hosts to the Vault server
  - `8201/tcp` only if the selected Vault module requires cluster traffic

## Risks And Unknowns

- No discoverable private Vault or EC2 modules are currently available in `pcarey-org`.
- It is unknown whether the eventual private modules can output a consumable CA artifact for downstream clients.
- It is unknown whether the eventual private modules support `user_data` or equivalent bootstrap hooks on both Linux and Windows.
- If CA distribution requires raw infrastructure resources such as S3, SSM, or Secrets Manager, that would conflict with the consumer-only workflow unless private modules wrap those resources.

## Assessment

- The bootstrap pattern is technically reasonable.
- The request remains blocked at design time by private module availability, not by Vault itself.
